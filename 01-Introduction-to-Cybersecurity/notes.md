# Introduction to Cybersecurity Notes

## What is Cybersecurity?

Cybersecurity is the practice of protecting computers, networks, applications, and data from unauthorized access, attacks, damage, or theft.

Cybersecurity is important because modern organizations rely on technology to store information, communicate, and operate their businesses.

---

# The CIA Triad

The CIA Triad is a fundamental model used in cybersecurity.

## Confidentiality

Confidentiality ensures that information is only accessible to authorized users.

Examples:
- Password protection
- Encryption
- Access controls
- User permissions

## Integrity

Integrity ensures that data remains accurate and has not been changed by unauthorized users.

Examples:
- File checksums
- Digital signatures
- Security logs

## Availability

Availability ensures that systems and information are accessible when needed.

Examples:
- Backups
- Redundant systems
- Disaster recovery plans

---

# Common Cybersecurity Threats

## Malware

Malware is malicious software designed to damage systems, steal information, or gain unauthorized access.

Examples:
- Viruses
- Worms
- Trojans
- Ransomware
- Spyware

## Phishing

Phishing is a social engineering attack where attackers attempt to trick users into revealing sensitive information.

Examples:
- Fake emails
- Fake websites
- Fraudulent messages

## Social Engineering

Social engineering targets human behavior instead of directly attacking technology.

Examples:
- Pretending to be IT support
- Creating urgency
- Manipulating users into sharing information

## Password Attacks

Attackers may attempt to gain access through weak or stolen passwords.

Examples:
- Brute force attacks
- Credential stuffing
- Password guessing

---

# Security Principles

## Strong Authentication

Using strong authentication helps prevent unauthorized access.

Examples:
- Strong passwords
- Multi-factor authentication (MFA)
- Biometrics

## Least Privilege

Users should only have the permissions required to perform their tasks.

Benefits:
- Reduces damage from compromised accounts
- Limits unauthorized access

## Defense in Depth

Using multiple layers of security provides better protection.

Examples:
- Firewalls
- Antivirus software
- Access controls
- Encryption
- Monitoring

---

# Encryption

Encryption converts readable information into an unreadable format to protect data.

Important concepts:
- Plaintext = readable data
- Ciphertext = encrypted data
- Encryption key = used to encrypt/decrypt information

Encryption helps protect:
- Personal information
- Financial data
- Company information
- Communications

---

# Importance of Cybersecurity in IT

IT professionals need cybersecurity knowledge because they manage systems, users, and networks.

Security responsibilities include:
- Protecting user accounts
- Keeping systems updated
- Identifying risks
- Responding to incidents
- Following security best practices
