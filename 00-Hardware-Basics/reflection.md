# Hardware Basics Reflection

## What I Learned

Before completing Hardware Basics, I understood computers from a user perspective but wanted to better understand how the individual components work together.

I learned about:

- CPU functions and performance considerations
- RAM and memory requirements
- Storage technologies including HDDs and SSDs
- Motherboards and component compatibility
- Power supplies and hardware requirements
- Expansion cards and peripherals
- Basic networking hardware

## Hands-On Experience

After learning these concepts, I applied my knowledge by successfully building a gaming PC for my brother.

During this project, I:

- Selected compatible PC components
- Installed the CPU, RAM, storage, GPU, and power supply
- Managed cable connections and system organization
- Installed and configured the operating system
- Verified that all hardware was functioning correctly
- Troubleshot issues during setup

## Reflection

Building a computer helped me understand that hardware knowledge is not just theoretical. Understanding how components interact makes troubleshooting easier and is an important foundation for IT support.

This experience increased my confidence in diagnosing hardware problems, upgrading systems, and supporting users with computer issues.
