# Hardware Basics Notes

## Motherboard

The motherboard connects the major components of a computer including the CPU, RAM, storage, and expansion cards.

## CPU

The CPU executes instructions and performs calculations needed for programs.

## RAM

RAM provides temporary high-speed storage for active programs and processes.

## Storage

HDDs provide large capacity storage while SSDs provide faster access times.

## Networking Hardware

Common networking devices include:

- Routers
- Switches
- Wireless Access Points
- Network Interface Cards
