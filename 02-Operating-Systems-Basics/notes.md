# Operating Systems Basics — Notes

## 1. What is an Operating System?

An operating system (OS) is system software that manages a computer's hardware and provides an environment for applications to run.

The operating system acts as an intermediary between the hardware and the software running on the device.

### Main responsibilities

* Managing hardware resources
* Managing applications and processes
* Managing memory
* Managing files and storage
* Managing users
* Providing security
* Providing a user interface

---

## 2. Operating System Components

Key components and concepts covered in the course:

* Kernel
* User interface
* File system
* Processes
* Memory management
* Device management
* Security

### Kernel

The kernel is the core component of an operating system. It provides communication between software and hardware and manages important system resources.

---

## 3. Processes

A process is a program that is currently running.

Operating systems manage processes by allocating resources such as CPU time and memory.

Important concepts:

* Programs vs. processes
* Process management
* Multitasking
* CPU scheduling

---

## 4. Memory

Operating systems manage the computer's memory and allocate memory to processes.

Important concepts:

* RAM
* Virtual memory
* Memory allocation
* Memory management

---

## 5. Storage and File Systems

Operating systems organize data using file systems.

Important concepts:

* Files
* Directories/folders
* File paths
* Storage devices
* File systems

---

## 6. User Interfaces

Operating systems can provide different types of interfaces.

### Graphical User Interface (GUI)

Uses graphical elements such as:

* Windows
* Icons
* Menus
* Pointers

### Command-Line Interface (CLI)

Allows users to interact with the operating system by entering commands.

The CLI will become particularly important when I begin working with Linux.

---

## 7. Operating System Examples

Examples of operating systems include:

* Microsoft Windows
* Linux
* macOS
* Android
* iOS

Different operating systems are designed for different types of devices and use cases.

---

## 8. Key Takeaways

* The operating system manages computer hardware and software.
* The kernel is a core part of an operating system.
* Processes are running instances of programs.
* Operating systems manage memory, storage, devices, and users.
* GUIs and CLIs provide different ways to interact with an operating system.
* Understanding operating systems provides an important foundation for learning Linux.
