# Operating Systems Basics — Reflection

## Why I Took This Course

I am taking Operating Systems Basics as part of my preparation for further study in Linux, networking, and IT administration.

Before beginning more advanced Linux work, I wanted to strengthen my understanding of what an operating system actually does and how it interacts with computer hardware and applications.

## What I Learned

Through this course, I learned more about the role of an operating system in managing computer resources and providing an environment for applications to run.

Some of the concepts I focused on include:

* Operating system components
* The kernel
* Processes
* Memory management
* File systems
* User interfaces
* Hardware and software interaction

## What I Found Interesting

One of the most useful concepts for me was understanding that an operating system is much more than the graphical interface that I interact with every day.

The OS is responsible for managing resources and coordinating communication between applications and the underlying hardware.

This gives me a better foundation for understanding why Linux works differently from simply using Windows as an end user.

## Connection to My Goals

This course connects directly to my goal of developing practical Linux and IT administration skills.

Understanding operating systems will help me when I begin working with Linux processes, services, filesystems, permissions, networking, and system administration.

I also expect this knowledge to help me understand the differences between Windows and Linux as I continue developing my technical skills.

## What I Want to Learn Next

My next areas of study are:

1. Cisco Packet Tracer and networking fundamentals
2. Linux fundamentals
3. Linux command-line administration
4. Networking on Linux
5. Python for automation

Eventually, I want to apply these skills through a hands-on Linux homelab and document the work on GitHub.

## Overall Reflection

This course provided me with a stronger foundation for understanding operating systems before moving into more hands-on Linux work. Rather than only learning individual commands, I now have a better understanding of the role an operating system plays in a computer system.

I plan to build on this foundation through hands-on practice and progressively more advanced IT projects.
